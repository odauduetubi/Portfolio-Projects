# Project Synopsis

As a starting point to this project, we shall be collecting data from various sources. Thereafter, we shall be cleaning them to improve their quality. 

Next, we explored the processed data. As a part of this explotory data analysis, we practiced with SQL, honing skills as we query the data and gather insights.  

Furthermore, we gathered insights into the data by applying some basic statistical analysis and data visualization, where we were able to see directly how variables might be related to each other.   

Finer levels of detail were drilled down by splitting the data into groups defined by categorical variables or factors in the data.  

In the end, I built, evaluated, and refined predictive models for discovering more exciting insights.
